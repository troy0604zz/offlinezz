# 依赖与工具完整清单

清单基于本次实际可构建代码。后端可执行 JAR 内的每一个库文件见 `packaged-jars.txt`（150 个 JAR，不含目录项），完整 Maven 依赖关系见 `maven-dependency-tree.txt`，前端精确传递版本见 `web/package-lock.json`。

## 后端直接依赖

| 类别 | 组件 | 版本/来源 | 用途 |
|---|---|---|---|
| 运行时 | JDK | 17 | Java 运行环境 |
| 框架 | Spring Boot | 3.5.9 | Web、配置、自动装配 |
| Web | spring-boot-starter-web | Boot 管理 | REST API、内嵌 Tomcat |
| 校验 | spring-boot-starter-validation | Boot 管理 | 请求参数校验 |
| 安全 | spring-boot-starter-security | Boot 管理 | 登录认证、接口鉴权、BCrypt 密码校验 |
| 运维 | spring-boot-starter-actuator | Boot 管理 | 健康、指标端点 |
| 数据 | spring-boot-starter-jdbc | Boot 管理 | JdbcClient/JdbcTemplate |
| 迁移 | flyway-core / flyway-database-oracle | 11.7.2 | H2/Oracle 平台库版本迁移 |
| SQL | jsqlparser | 5.3 | SQL AST 只读校验 |
| 文档 | tika-core / tika-parsers-standard-package | 3.3.2 | PDF、Word、Excel、文本解析 |

## 内网运行服务与工具

| 必需性 | 组件 | 建议 | 说明 |
|---|---|---|---|
| 必需 | Linux JDK | 17 LTS x86_64 | 运行后端 |
| 必需 | Oracle Database | 19c | 平台元数据和当前 MVP 演示业务库；建议平台 Schema 与业务只读账号隔离 |
| 外部必需 | 内网模型网关 | 由内网平台固定版本 | 提供 OpenAI-compatible Chat 与 Embedding 接口 |
| 可选 | Ollama | 源端与目标端同一固定版本 | 没有内网模型网关时的本地模型运行方案；本次内网迁移不需要 |
| 必需 | Qdrant | 固定 x86_64 MUSL 发布版 | 向量检索；CentOS 7 先做兼容性验证 |
| 可选 | Nginx | 内网仓库固定版本 | 高并发、HTTPS 或统一网关场景下的静态页面与 API 反向代理 |
| 必需（二选一） | Node.js 内置 HTTP 服务 | 使用目标机已安装版本 | 无 Nginx 时运行 `deploy/node/static-server.mjs`，不需要 npm 模块 |
| 构建时 | Maven | 3.9.11 | 后端构建；生产运行机不需要 |
| 构建时 | Node.js/npm | Node 20/22 LTS | 前端构建；生产运行机不需要 |
| 可选 | Redis | 企业已有稳定版 | 分布式缓存、任务队列；MVP 未依赖 |
| 可选 | Prometheus/Grafana | 企业已有版本 | 指标采集与仪表盘 |
| 可选 | ClamAV | 内网批准版本 | 上传文件病毒扫描 |
| 可选 | NAS/共享存储 | 企业标准 | 原始文档、解析产物、报告存储 |
| 联网测试可选 | 千问官方 API | `qwen3.8-max` / `qwen3.7-text-embedding` | 本机联网效果和耗时对比；纯内网不依赖 |

## 离线搬运物料

1. `release/ai-bi-server.jar` 与前端 `web/dist/`。
2. JDK 17、Nginx RPM 及其依赖；Oracle 数据库连接信息和网络放行单。
3. Qdrant x86_64 MUSL 二进制、配置、systemd 文件、SHA-256。
4. 内网模型网关的 Chat/Embedding 地址、模型 ID、Token、向量维度与超时配置；不搬运 Ollama 和本地模型。
5. `aibi.env`、Oracle 迁移/初始化脚本、数据库备份、Qdrant 快照（若已有索引）。
6. 源码、`pom.xml`、`package-lock.json`、可选离线 Maven 仓库与 npm 缓存。

当前项目已经在 `offline` 目录内提供 Maven 3.9.11 和经过严格离线构建验证的项目专用仓库；内网二次开发不再依赖目标机原有 `.m2/repository` 是否完整。使用方法见 `docs/离线Maven仓库与二次开发说明.md`。
7. 软件物料清单、许可证、安全扫描报告和回滚包。

生产前必须在隔离区执行病毒扫描、哈希核验和许可证审查。模型文件体积大，建议用加密移动介质并保存分片校验值。
