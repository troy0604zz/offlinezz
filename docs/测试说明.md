# 测试说明

## 自动测试

后端包含 SQLGuard 单元测试、查询编排与报表导出集成测试、模型运行配置测试和登录权限集成测试。标准环境执行 `mvn test`；当前最终构建共 11 个测试，全部通过。权限测试覆盖未登录 401、越权 403、三类角色访问矩阵和退出后令牌失效。导出测试覆盖结果快照、正向反馈、Excel、CSV 和 XML。`scripts/smoke-test.ps1` 用于无需外部服务的 Mock 回归，`scripts/smoke-test-real.ps1` 用于 Oracle/Ollama/Qdrant 的真实端到端验收。

前端执行 `npm run build`，同时完成 TypeScript 类型检查和生产构建。

## 冒烟验收

启动后端后执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\smoke-test-real.ps1 -IncludeReport`。脚本先使用 `AIBI_TEST_USERNAME` / `AIBI_TEST_PASSWORD` 登录（本机默认 `ai_admin` / `Aibi@123`），再检查健康状态、real 平台模式、BGE-M3 文档向量化、Qdrant 检索、月度净销售额标准 SQL、Oracle 真实结果和报告生成。最终验收结果为 `PASS`：Oracle 返回预期 3 行，Qdrant `aibi_sales` 有持久化向量点，报告包含 2 个成功查询章节。

另以未命中标准案例的问题“统计所有已完成订单涉及的成交客户总数”验证真实 Qwen3.5 生成链路：模型生成 Oracle CTE SQL，SQLGuard 校验后由 Oracle 执行，结果为 5，端到端约 3.7 秒。

查询结果下载已在 Oracle 19c 真实环境验证：确认前下载返回 HTTP 400；提交 5 分正向反馈后，可生成 Excel、CSV 和 XML。验收文件分别具有 ZIP/XLSX `PK` 文件签名、UTF-8 BOM 和合法 `queryReport` XML 根节点，5 行查询结果在三种格式中保持一致。

## 黄金问题

`test-data/golden_questions.jsonl` 包含正确性和攻击性问题。NL2SQL 质量不能只看 SQL 能否执行，应同时核对指标口径、表集合、连接路径、时间过滤、结果值和安全拒绝率。

## Foundry 360 综合数据验收

`test-data/foundry360` 已在本机 Oracle 19c 真实装载，共 25 张表、2359 行业务数据。验收确认：跨表客户归属不一致为 0、每个制造批次恰好有 WAT/CP 两个测试阶段、无负产出或良品大于完成数、无超范围良率、12 个产品均有 CP 测试数据。

训练中心已导入 25 个 Schema、34 个指标、39 条关系、59 个同义词、24 条已发布标准 SQL、24 个对应黄金问题和 9 份知识文档。Windows PowerShell 5.1 导入脚本使用 .NET HttpClient 显式 UTF-8，并把顶层 JSON 数组展开后执行幂等检查和发布。

- 对应标准问题黄金评测状态 `PASSED`，得分 1.0，生成 SQL 与期望 SQL 一致。
- 24 条 Foundry 360 标准问题已逐条通过真实问答 API，24/24 状态为 `COMPLETED`，无 SQL 解析、白名单或 Oracle 执行失败。
