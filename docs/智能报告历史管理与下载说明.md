# 智能报告历史管理与下载说明

## 页面功能

“智能报告”页面左侧显示当前数据域内的全部历史报告，包含状态、创建时间和创建人。点击已完成的报告可在右侧打开完整内容快照；历史记录和报告预览区域都提供下载入口。

下载弹窗支持：

- PDF（`.pdf`）：适合分享、审批和归档。
- Word（`.docx`）：适合继续编辑和补充说明。

导出文件包含报告标题、生成信息、执行摘要、分析要求、各分析章节、查询结果表、查询依据 SQL、生成提示和行动建议。文件直接使用报告生成完成时保存在 Oracle `report_job.content_json` 中的内容快照，不会重新调用大模型，也不会重新执行 SQL。

## 删除规则

- 报告创建人可以删除自己创建且已经完成或失败的报告。
- AI 管理员可以删除当前可访问数据域内其他用户创建的报告。
- 普通报告用户不能删除其他用户的报告。
- 正在生成的报告不能删除，避免生成过程与删除操作互相覆盖。
- 删除只清理 `report_job` 中的报告快照，不删除该报告引用的数据问答、标准 SQL、训练素材或业务数据。
- 删除成功前会写入 `REPORT_DELETED` 审计事件；审计记录不会随报告删除。

页面删除按钮具有确认弹窗和独立 loading 状态，可阻止用户重复点击。

## 后端接口

| 方法 | 地址 | 说明 |
|---|---|---|
| `GET` | `/api/v1/reports?domain={domain}` | 查询当前数据域历史报告，并返回 `can_delete` |
| `GET` | `/api/v1/reports/{id}` | 读取历史报告内容快照 |
| `GET` | `/api/v1/reports/{id}/export?format=pdf` | 下载 PDF |
| `GET` | `/api/v1/reports/{id}/export?format=docx` | 下载 Word |
| `DELETE` | `/api/v1/reports/{id}` | 按创建人/管理员权限删除报告 |

下载会写入 `REPORT_EXPORTED` 审计事件。所有接口继续执行登录权限和数据域 `SMART_REPORT` 访问校验，不能跨数据域读取、下载或删除报告。

## 离线迁移

Word 由项目已有的 Apache POI 生成；PDF 使用兼容 JDK 17 的 OpenPDF 2.0.5 生成，不依赖 Microsoft Word、LibreOffice、浏览器或外部转换服务。OpenPDF JAR、POM 和父 POM 已加入项目的 `offline/maven-repository`，`offline/OFFLINE_SHA256SUMS.txt` 也已同步更新，可在无外网 Windows 或 CentOS 环境中继续编译。
