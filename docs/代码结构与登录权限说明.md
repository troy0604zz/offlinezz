# 代码结构与登录权限说明

## 前端结构

前端入口只负责挂载 Vue、Pinia、Router 和 Element Plus。页面不直接创建 Axios，也不把多个业务模块堆在一个组件内。

```text
web/src
├── components
│   ├── common       通用页面标题、空状态
│   ├── query        问题输入、结果表格、ECharts 图表
│   └── training     训练概览、数据表格、编辑弹窗
├── layouts          登录后的统一侧边栏和顶部用户区
├── router           路由表和权限守卫
├── services         按 auth/query/report/training/platform 拆分 API
├── stores           Pinia 登录状态
├── styles           设计变量和全局基础样式
├── types            各业务模块 TypeScript 类型
├── utils            会话本地存储等无界面工具
└── views            登录、问答、报告、训练中心页面
```

新增页面时，先在 `views` 建页面，再在 `router/index.ts` 声明路由；接口放入对应 `services` 文件，跨页面状态才放入 `stores`。页面专用组件放在所属业务目录，只有真正跨模块复用的组件才放 `common`。

## 后端结构

后端按业务能力分包：`auth` 负责用户、角色、权限和会话；`query` 负责受控 NL2SQL；`report` 负责报告编排；`training`、`semantic`、`knowledge` 共同组成训练中心；`common` 仅放公共错误和数据库结果适配。

认证使用随机 256 位 Bearer Token。数据库只保存令牌 SHA-256 摘要，可立即注销或禁用用户；密码使用 BCrypt。`SecurityConfig` 是服务端权限边界，前端隐藏菜单不能替代服务端鉴权。

## 权限与账号

| 权限代码 | 模块/接口 |
|---|---|
| `DATA_QUERY` | `/api/v1/questions/**`、`/api/v1/query-runs/**` |
| `SMART_REPORT` | `/api/v1/reports/**` |
| `AI_TRAINING` | `/api/v1/admin/**` |

| 本机账号 | 角色 | 权限 |
|---|---|---|
| `question_user` | `ANALYST` | `DATA_QUERY` |
| `report_user` | `REPORTER` | `DATA_QUERY`、`SMART_REPORT` |
| `ai_admin` | `AI_ADMIN` | 全部三项 |

三者本机初始密码均为 `Aibi@123`，仅用于隔离测试。角色、权限、用户及会话表由 Flyway V6 创建：`app_user`、`app_role`、`app_permission`、`app_user_role`、`app_role_permission`、`auth_session`。

要增加新角色，不要在 Vue 页面硬编码用户名。应在数据库中创建角色并配置权限关系；前端导航和路由根据登录接口返回的 `permissions` 自动生效，后端根据同一权限代码拒绝越权请求。

## 登录接口

- `POST /api/v1/auth/login`：用户名密码登录，返回访问令牌、失效时间和用户权限。
- `GET /api/v1/auth/me`：验证当前会话并返回最新权限。
- `POST /api/v1/auth/logout`：立即撤销当前令牌。

前端 Axios 拦截器统一附加 `Authorization: Bearer <token>`。接口返回 401 时清理本地会话并返回登录页；返回 403 时保留登录状态并提示无权访问。

## 生产迁移注意事项

1. 删除或禁用三个本机验收账号，创建正式账号或接入企业 SSO/LDAP/OIDC。
2. 把平台元数据库账号和业务查询只读账号拆开，业务账号只允许访问审核后的表或视图。
3. 将 Swagger/OpenAPI 置于内网管理网段或在生产关闭。
4. 配置 HTTPS、反向代理安全头、密码策略、失败锁定和安全审计告警。
5. 多实例部署时继续使用 Oracle 会话表即可共享登录状态，并定期清理过期会话。
