# 当前实现范围与后续开发

## 已实现的可运行 MVP

- Vue3 登录、权限路由、数据问答、表格、ECharts、报告和语义/知识管理页面。
- Spring Boot 模块化后端、Flyway、H2/Oracle 19c 双配置。
- 数据库用户、角色、权限、可撤销会话和三类模块级 RBAC。
- MockLlmProvider 与真实 Ollama `/api/chat` 适配器。
- InMemoryVectorStore 与真实 Ollama `/api/embed` + Qdrant REST 适配器。
- DDL 演示域、指标和关系语义层、文档上传/Tika 解析/分块。
- 确定性 Mock NL2SQL、多表查询、退款预聚合、结果解释和图表规格。
- JSqlParser 单语句/只读/对象白名单/危险函数校验，超时和最大行数。
- 按用户授权的数据域切换；域内数据源、训练资产、问答、反馈、报告和使用记录强隔离。
- 数据域与 Oracle 数据源一对一配置、连接测试、AES-GCM 凭据加密和域内成员授权。
- 查询历史、反馈、审计事件、用户要求驱动的动态多章节报告、报告历史详情、Actuator、Swagger。
- AI 训练中心：DDL/Schema、指标、表关系、同义词、标准 SQL、黄金问题评测和训练概览，训练资产支持编辑和删除。
- 标准 SQL 发布后参与 Mock 相似匹配，并作为真实 Qwen3.5 的 Few-shot 上下文；Mock 文档索引可在重启后恢复。
- Oracle 作为训练资产权威库；Qdrant 仅保存文档、DDL、指标说明和标准问题的带版本检索投影，不保存凭据、权限、指标公式和完整标准 SQL。
- 向量模型切换强制重建全部活动域索引，成功后清理当前集合前缀下的非活动 Embedding 集合。
- CentOS 7 systemd、Nginx、Qdrant、Ollama、环境变量模板和测试数据。

## 企业正式上线前仍需完成

- SSO/OIDC、ABAC、租户与行列级数据权限注入；现有本地 RBAC 需接入企业身份源。
- 企业级凭据保险箱/KMS、独立业务连接池、连接配额和 Oracle 之外的数据库方言适配；当前独立域连接采用按查询建立只读连接。
- 完整审批流、版本差异、回滚、关系可视化图和指标血缘。
- 更强的 SQL AST 改写、EXPLAIN 成本门禁、人工审批和结果脱敏。
- 异步任务、SSE、取消/重试、并发限流、熔断、缓存和多实例部署。
- 报告编辑、PDF/PPTX 导出、定时分发与快照固化。
- Qdrant alias/双集合发布、删除/重建、快照恢复和模型升级流程。
- 真实 Qwen3.5/BGE-M3/Qdrant/Oracle 19c 的集成测试、黄金集评测和安全测试。
- 可观测链路、告警、备份恢复、容量压测、SBOM/漏洞治理。

因此当前交付应视为“可运行、可验证的第一条垂直切片”，不是已经完成所有企业生产能力的最终版。
