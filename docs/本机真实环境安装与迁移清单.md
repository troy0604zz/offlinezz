本机发现了既有 `D:\Tool\Oracle19\oradata\ORCL` 数据文件，安装过程没有删除、移动或覆盖它们；本项目使用独立的 `AIBICDB/AIBIPDB1`。

## 6. 应用配置与脚本

- 配置模板：`deploy\local-real.config.ps1.example`
- 实际密码配置：`runtime\local-real.config.ps1`；密码清单：`runtime\oracle-local-secrets.txt`；`runtime` 已加入 `.gitignore`
- Oracle 初次建库：`scripts\install-oracle19c-database.ps1`
- Oracle 建库后账号收尾：`scripts\finish-oracle19c-setup.ps1`
- 仅重置本机 AIBI 测试 Schema：`scripts\reset-local-aibi-schema.ps1`（会删除 AIBI 对象，只用于空测试库）
- 启动：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\start-local-real.ps1`
- 检查：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\verify-local-real.ps1`
- real 验收：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\smoke-test-real.ps1`
- 停止应用：`powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\stop-local-real.ps1`
- 停止应用及 Ollama/Qdrant：在停止命令后增加 `-IncludeInfrastructure`

本机 PowerShell 执行策略禁止直接双击/运行未签名脚本，因此命令显式使用一次性的 `-ExecutionPolicy Bypass`；没有修改系统全局执行策略。

## 9. 离线迁移步骤

1. 在目标服务器安装企业批准的 Oracle 19c RU，创建独立 PDB 和 AIBI Schema。
2. 复制 `release\ai-bi-server.jar`、`web\dist`、部署脚本和配置模板。
3. 复制 Qdrant 可执行文件及数据，或在目标机重建集合后重新上传知识文档。
4. 复制整个 Ollama 模型目录，并核对两个模型 digest。
5. 修改目标机的 JDBC、存储目录和服务地址，不复制本机 `runtime` 密码文件。
6. 首次启动检查 Flyway V1-V5、Oracle 健康状态、模型标签和 Qdrant 维度。
7. 执行 `scripts\smoke-test-real.ps1 -IncludeReport`，结果必须为 `PASS`。
