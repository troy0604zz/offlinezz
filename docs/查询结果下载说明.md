# 查询结果下载说明

## 用户流程

1. 用户在“数据问答”提交问题并查看查询结果、图表和 SQL。
2. 用户点击“结果正确”。
3. 系统先记录 5 分正向反馈，再显示下载格式弹窗。
4. 用户选择 Excel、CSV 或 XML，也可以选择“暂不下载”。
5. 确认过的结果会继续显示“下载报表”按钮，方便稍后再次下载。

## 支持格式

| 格式 | 扩展名 | 典型用途 |
|---|---|---|
| Excel | `.xlsx` | 继续分析、筛选和制作图表 |
| CSV | `.csv` | 数据交换、脚本和批量处理；使用 UTF-8 BOM |
| XML | `.xml` | 系统集成、结构化交换和归档 |

## 一致性与安全

- 成功查询后，系统把本次返回行序列化到 `query_run.result_json`。
- 下载使用结果快照，不会重新执行生成的 SQL，因此文件内容与用户确认时看到的数据一致。
- 下载接口要求该 `query_run` 至少存在一条评分不低于 4 的反馈。
- 下载接口继续使用 `DATA_QUERY` 权限；未登录或无权限用户无法访问。
- 每次下载都会记录 `QUERY_EXPORTED` 审计事件，包含格式和行数，不记录报表文件内容。
- 旧的 V7 迁移前查询没有结果快照，需要重新提问后才能下载。

## API

```text
GET /api/v1/query-runs/{queryRunId}/export?format=xlsx
GET /api/v1/query-runs/{queryRunId}/export?format=csv
GET /api/v1/query-runs/{queryRunId}/export?format=xml
```

成功时返回附件字节流和对应的 `Content-Type`、`Content-Disposition`。不支持的格式返回 HTTP 400。
