# AI 查询安全规范

1. 只允许 SELECT 或 WITH...SELECT。
2. 禁止 INSERT、UPDATE、DELETE、MERGE、DROP、ALTER、TRUNCATE、CALL、COPY。
3. 禁止 SELECT *；必须显式选择需要的列。
4. 默认最多返回 200 行，绝对上限 1000 行，执行超时 15 秒。
5. 只能访问白名单表：region、customer、product、sales_order、sales_order_item、refund。
6. 涉及金额必须说明指标口径；涉及时间必须说明所用日期字段。
7. 所有问题、检索证据、生成 SQL、执行状态和用户反馈都需写入审计日志。
