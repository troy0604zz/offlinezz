# 数据字典与枚举说明

## 日期字段选择

- 商务接单趋势：sales_order.order_date。
- 客户要求交期：sales_order.requested_delivery_date。
- 订单行承诺交期：order_line.promised_date。
- 制造投片：wafer_lot.start_date。
- 制造完成：wafer_output.completion_date。
- 良率：yield_result.test_date。
- 收入与出货：shipment.ship_date。
- 客户收货与 OTIF：shipment.actual_delivery_date。
- 质量：quality_incident.opened_date / closed_date。
- 库存：inventory_snapshot.snapshot_date。

## 常用状态

- order_status：COMPLETED、ON_HOLD、CANCELLED。
- line_status：CONFIRMED、ON_HOLD、CANCELLED。
- lot_status：COMPLETED、ON_HOLD。
- shipment_status：DELIVERED、CUSTOMER_HOLD。
- forecast_status：FROZEN、OPEN。
- incident_status：OPEN、CLOSED。
- opportunity_stage：RFQ、PROPOSAL、SAMPLE、QUALIFICATION、WON、LOST。
- milestone_status：PLANNED、COMPLETED、DELAYED。

## 单位

- 金额均为 USD；原始客户币种只保留在客户和订单属性，不用于本测试集换算。
- wafer 数均为片。
- 良率、概率、信心度、返点和市场增长率均以 0-100 百分数存储。
- cycle_time_days 与 aging_days 为自然日。
- downtime_hours 与 hold_hours 为小时。
- die_size_mm2 为平方毫米，geometry_nm 为纳米，wafer_size_mm 为毫米。
