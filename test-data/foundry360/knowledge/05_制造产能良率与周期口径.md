# 制造、产能、良率与周期口径

## 产能

产能计划粒度为 `fab_id + node_id + capacity_month`。

- 可用产能：`available_wafers`，已经考虑计划维护影响。
- 承诺产能：`committed_wafers`。
- 实际投片：`actual_start_wafers`。
- 产能利用率：实际投片 / 可用产能。
- 产能承诺率：承诺产能 / 可用产能。

利用率超过 100% 需要作为过载异常显示，不能截断为 100%。

## 晶圆投片与产出

投片以 `wafer_lot.actual_start_wafers` 统计。产出以 `wafer_output.good_wafers` 统计。一个批次只有一条 output，但有多个 yield stage。

## 良率

聚合 CP 或 WAT 良率时使用：`SUM(good_die)/SUM(tested_die)`。禁止直接平均每个 lot 的百分比，否则小批次与大批次权重相同。

- WAT：晶圆验收测试，偏向工艺参数。
- CP：晶圆电性测试，作为 Product 360 默认良率。
- `electrical_yield_pct` 的存储范围是 0 到 100，不是 0 到 1。

## Cycle Time

实际周期来自 `wafer_output.cycle_time_days`，标准周期来自 `process_route.standard_cycle_days`。周期达成率必须在 lot 粒度判断实际是否小于等于标准，再汇总。

设备停机分析应使用 `equipment_downtime`。停机损失产能不能与 capacity_plan.maintenance_loss_wafers直接相加，两者可能描述同一损失的不同视角。
