# 收入、价格、成本与毛利口径

## 收入确认

测试数据按客户验收口径确认晶圆收入：

`晶圆收入 = SUM(accepted_wafers × shipment.unit_price_usd)`

仅统计 `shipment_status='DELIVERED'`。运费不计入收入，客户暂扣状态不确认收入。订单金额不是收入，预测金额也不是收入。

## ASP

`ASP = 总晶圆收入 / 总验收晶圆数`

跨产品计算必须用加权平均，禁止直接平均各产品 ASP。

## 成本

单片晶圆成本由材料、制程、制造费用、探针测试和报废成本构成。成本表粒度为产品月：

`unit_cost = material_cost + process_cost + overhead_cost + probe_cost + scrap_cost`

出货记录要按 `product_id` 与出货月份关联成本。若月份没有成本，不应自动使用 0；报告应标记成本缺失，或按经批准规则取最近有效成本。

## 毛利

`毛利额 = SUM(accepted_wafers × (actual_unit_price - unit_cost))`

`毛利率 = 毛利额 / 晶圆收入 × 100%`

跨产品、客户、应用和工艺节点计算毛利率必须先汇总收入与成本再相除，禁止平均明细毛利率。

价格协议表用于分析合同价差：实际单价低于协议价时称为负价差。协议有效期必须覆盖出货日期，同一产品不同年度不能错配。
