# 预测、订单、交付与库存口径

## 预测准确率

预测与实际必须按客户、产品、自然月对齐。测试集使用 `forecast_version='PLAN_2026'`。

`准确率 = MAX(0, 1 - ABS(预测量-实际出货量)/预测量) × 100%`

预测量为 0 时准确率为空，不定义为 100%。多个产品汇总时先加总预测与实际，再计算组合准确率。

## Backlog

未交付积压量以有效订单行为基础：

`backlog = ordered_wafers - delivered accepted_wafers`

取消订单及取消行不进入 backlog。出货必须先按 `order_line_id` 聚合，否则多批次、多出货会放大订单量。

## OTIF

订单行在客户实际收货日期不晚于 promised_date，且累计 accepted_wafers 不少于 ordered_wafers，才算按时足量。OTIF 是满足条件的订单行数 / 应交付订单行数，不是晶圆数量比例。

## 库存

库存表是月末快照，包含 WIP 和 FINISHED_GOODS。查询某月库存使用该月最后快照；查询当前库存使用全表最新 snapshot_date。禁止跨月相加。

默认超龄库存定义为 `aging_days > 90`。reserved_wafers 已被订单或客户预留，不能当作自由可用库存。
